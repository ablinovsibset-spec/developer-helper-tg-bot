# Скилл: утренняя сводка (Тип B — рутина)

Последовательность шагов для запроса вида «доброе утро», «утренняя сводка»,
«что на сегодня» и подобных. Выполняй шаги по порядку инструментом `exec`,
затем выдай итоговую сводку одним сообщением.

## Шаг 1. Погода в Минске

Запроси текущую погоду в Минске по правилам скилла **wttr-in-api**
(см. секцию `wttr-in-api`): один компактный запрос
`curl -s --max-time 10 "wttr.in/Минск?lang=ru&format=j1"` — этого достаточно
и для температуры, и для краткого прогноза на день.

## Шаг 2. События дня

Попробуй получить события календаря на сегодня локальными утилитами
(попробуй по очереди, остановись на первой работающей):

```bash
icalBuddy -f -n -ea -nc eventsToday
khal list today
```

- Если утилита недоступна (stderr «command not found») или календарь пуст —
  это не ошибка: пропусти шаг и отметь в сводке, что календарь не подключён.
- Не пытайся установить утилиты и не выполняй другие команды для календаря.

## Шаг 3. Итоговая сводка

Собери финальное сообщение пользователю:

1. Короткое приветствие и дата.
2. Погода в Минске: 1–2 строки (температура, ощущается как, осадки/ветер
   на день) — компактно, по правилам wttr-in-api.
3. События дня списком (если найдены) или пометка, что календарь недоступен.
4. При желании — одна строка совета по погоде (зонт/тёплая одежда).

Требования к сводке:

- Объём — не более 4000 символов.
- Один финальный ответ, без промежуточных сообщений о выполнении шагов.
- Если запрос погоды не удался после повтора (см. wttr-in-api), всё равно
  выдай сводку с тем, что есть, и отметь недоступность погоды.
