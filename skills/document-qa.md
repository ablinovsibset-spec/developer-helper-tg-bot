# Скилл: вопросы по загруженным документам (Тип A — инструкция к инструментам)

Правила работы с личным индексом документов пользователя: `.txt`, `.md`,
`.docx`, `.pdf`, загруженные прямо в чат. Индекс личный: видны только
документы того, кто задаёт вопрос.

## Когда искать по документам

Вызывай `search_documents`, когда вопрос касается:

- содержания загруженного файла («что написано в…», «сколько дней отпуска»);
- политик, регламентов, инструкций, гайдов, договоров;
- формулировки, которая могла быть в документе, даже если файл не назван.

Не подменяй поиск догадкой: ответ «по документу» без вызова инструмента —
ошибка, даже если тема тебе знакома.

## Как формулировать запрос

1. `query` — вопрос или ключевая формулировка на языке документа: поиск
   семантический и текстовый, поэтому естественная фраза работает лучше
   набора слов.
2. Follow-up с местоимением («а можно перенести их?») формулируй
   **самодостаточным** query: подставь референт из предыдущей реплики
   («можно ли перенести дни отпуска на следующий год»). История сессии
   подмешивается в поиск, но явный запрос надёжнее.
3. Не нашлось — переформулируй одним синонимом или термином из документа
   и попробуй ещё раз. Больше двух-трёх попыток бессмысленно.
4. Нужен обзор доступного — напомни пользователю про `/documents`;
   сам список инструментом не достаётся.

## Как отвечать

1. Опирайся только на текст найденных фрагментов.
2. Указывай источник строкой `Источник: <имя файла>`; если в результате
   поиска есть страница PDF — копируй её: `Источник: file.pdf, стр. 17`
   (или диапазон `стр. 16–17`). Не выдумывай номер страницы, если его нет
   в результате инструмента.
3. Если фактов из нескольких файлов — перечисли все использованные.
4. Противоречие между фрагментами — покажи оба и назови их источники,
   не выбирай молча.
5. Пустой результат поиска — честный отказ: в загруженных документах
   этого нет. Общие знания можно дать только отдельно и прямо сказав,
   что это не из документа.

## Ограничения

- Сканы PDF без текстового слоя не распознаются — для них поиск пуст.
- Индекс обновляется только загрузкой файла; правки на стороне
  пользователя сами не подхватываются — нужна повторная отправка
  (файл с тем же именем заменяет прошлую версию).
- Удаление — команда `/delete <имя файла>`, инструментом не делается.
