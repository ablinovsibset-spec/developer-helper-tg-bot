# Скилл: топ-лента Habr (Тип A — инструкция к API)

Правила получения топ-статей Habr за последние сутки через инструмент `exec`
(curl + python3).

## Команда

Выполняй команду как есть, без модификаций и «улучшений» — кавычки и переносы
строк выверены, переписывание ломает синтаксис:

```bash
curl -sL --max-time 15 "https://habr.com/ru/rss/articles/top?fl=ru" | python3 -c 'import sys, xml.etree.ElementTree as ET
from datetime import datetime, timedelta, timezone
from email.utils import parsedate_to_datetime
items = ET.fromstring(sys.stdin.read()).findall(".//item")
now = datetime.now(timezone.utc)
for i in items:
    d = parsedate_to_datetime(i.findtext("pubDate"))
    if d >= now - timedelta(hours=24):
        print("%s | %s | %s" % (d.strftime("%d.%m %H:%M"), i.findtext("title"), i.findtext("link").split("?")[0]))'
```

Вывод — строки вида `дата | заголовок | ссылка`: статьи топ-ленты, вышедшие
за последние 24 часа (окно считается относительно текущего момента, дата из
системного промпта не нужна).

## Правила

1. Флаг `-L` обязателен: старые URL Habr отвечают 301-редиректом, без `-L`
   придёт пустой ответ.
2. `--max-time 15` — увеличенный относительно wttr.in таймаут на большой XML
   (~100 КБ); не сокращай его.
3. При таймауте или ответе HTTP 5xx подожди 2–3 секунды и выполни команду ещё
   раз (всего один повтор); при повторной ошибке считай источник недоступным
   и отметь это в ответе пользователю.
4. В сводку бери не более 10 первых строк вывода: лента уже отсортирована по
   рейтингу, порядок статей сохраняй как есть. Если свежих статей меньше 10 —
   бери столько, сколько есть («до 10» — потолок, а не норма).
5. UTM-хвосты ссылок (`?utm_source=…`) уже чистятся командой — дополнительные
   преобразования ссылок не нужны.

## Формат вывода пользователю

- Заголовок каждой статьи оформляй HTML-ссылкой `<a href="ссылка">Заголовок</a>`
  (у бота включён `parse_mode=HTML`) — без голого URL в тексте.
- Спецсимволы `&`, `<`, `>` в заголовках статей экранируй (`&amp;`, `&lt;`,
  `&gt;`), иначе HTML-разметка сообщения сломается.
