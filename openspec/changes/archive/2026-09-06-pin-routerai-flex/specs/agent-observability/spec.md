# agent-observability Delta

## ADDED Requirements

### Requirement: Фактическая стоимость поставщика
Запись телеметрии LLM-вызова SHALL содержать фактическую стоимость,
начисленную поставщиком за вызов (поле стоимости в usage ответа), отдельным
полем в единицах поставщика, без конверсии. Отсутствие поля в ответе
поставщика SHALL фиксироваться null, а не нулём (absence ≠ 0); нулевое
значение от поставщика фиксируется как честный ноль. Прогон при финализации
SHALL агрегировать фактическую стоимость суммой по своим вызовам. Оценочная
стоимость по прайсу продолжает записываться параллельно: оценка — для
сопоставимости экспериментов, факт — для сверки с биллингом поставщика.

#### Scenario: Поставщик вернул стоимость
- **WHEN** usage ответа содержит числовую стоимость вызова
- **THEN** запись телеметрии содержит её в отдельном поле и в агрегате прогона

#### Scenario: Поставщик не отдаёт стоимость
- **WHEN** поставщик не возвращает поле стоимости (локальный LM Studio)
- **THEN** поле записи равно null, оценка по прайсу продолжает записываться

#### Scenario: Стоимость ошибочного вызова
- **WHEN** попытка вызова завершилась ошибкой недоступности после повторов
- **THEN** фактическая стоимость не фиксируется (поставщик не начисляет её
  за неуспешный запрос)
