# exec-tool Delta

## MODIFIED Requirements

### Requirement: Выполнение консольной команды
Система SHALL предоставлять модели инструмент exec с единственным обязательным строковым параметром command, выполнять команду в изолированном Docker-контейнере (без доступа к файловой системе хоста, с исходящим доступом в интернет) и возвращать модели результат: стандартный вывод, вывод ошибок и код выхода. Команды выполняются в среде Linux (Alpine) с записываемым рабочим каталогом; файлы, созданные командой, доступны последующим командам в пределах того же сообщения и исчезают после его обработки.

#### Scenario: Успешная команда
- **WHEN** модель вызывает exec с командой, выводящей текст в stdout и завершающейся с кодом 0
- **THEN** модель получает результат, содержащий stdout команды и код выхода 0

#### Scenario: Команда с ненулевым кодом выхода
- **WHEN** модель вызывает exec с командой, завершающейся с ненулевым кодом (например, несуществующая утилита)
- **THEN** модель получает результат, содержащий stderr и фактический код выхода

#### Scenario: Файл переживает шаги одного сообщения
- **WHEN** модель вызывает exec с командой, создающей файл, и затем в том же сообщении вызывает exec с командой, читающей этот файл
- **THEN** вторая команда возвращает содержимое файла, созданного первой

#### Scenario: Состояние не переживает сообщение
- **WHEN** файл был создан командой при обработке одного сообщения, и модель читает его командой при обработке следующего сообщения
- **THEN** команда чтения завершается ошибкой отсутствия файла
