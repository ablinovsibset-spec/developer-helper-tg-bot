## Why

Живой код проекта (`main.py`, `config.py`, `llm/`) не покрыт ни одним тестом: всё поведение, обещанное спеками `telegram-bot` и `llm-provider` (чанкинг, обработка недоступности LLM, выбор провайдера, конфигурация из окружения), сейчас проверяется только вручную. Одновременно в пакете висят три пустые заглушки (`models.py`, `services.py`, `utils.py`), которые ничего не делают и лишь создают мёртвый вес.

## What Changes

- Добавить unit-тесты: `send_chunked` (чанкинг по 4096), `handle_text` (пересылка в LLM, ответ в тот же чат, отсутствие памяти, сообщение об ошибке при `LLMUnavailable`), `make_llm` (дефолтный/неизвестный провайдер, дефолты URL и модели), `telegram_token` (отсутствие токена).
- Добавить integration-тесты: локальный фейковый OpenAI-совместимый сервер на aiohttp; против него проверяются `OpenAICompatibleClient` (успешный ответ, заголовок `Authorization` с ключом и без него, HTTP 4xx/5xx, таймаут, битый JSON).
- Добавить dev-зависимости: `pytest`, `pytest-asyncio` (настроить asyncio-mode в `pyproject.toml`).
- **BREAKING** для внутренней структуры: удалить пустые заглушки `src/dev_helper_bot/models.py`, `services.py`, `utils.py`.
- Вычистить локальный мусор: корневой `__pycache__` (байткод от старой структуры), `.egg-info`, прочие кэши.

## Capabilities

### New Capabilities
- `test-suite`: требования к pytest-набору тестов — что каждый сценарий поведения из `telegram-bot` и `llm-provider` покрывается тестом, набор запускается одной командой `pytest` без внешних сервисов (Telegram и LLM имитируются фейками).

### Modified Capabilities
- `project-structure`: требование «Поддерживающие модули пакета» меняется — пустые файлы-заглушки больше не должны существовать; неиспользуемые модули пакета удаляются. Набор модулей пакета определяется фактической потребностью, а не заранее заданным списком.

## Impact

- **Код**: удаление `src/dev_helper_bot/{models,services,utils}.py`; изменений живой логики не требуется (при необходимости — минимальные правки ради тестируемости).
- **Зависимости**: новый `[dependency-groups] dev` (или эквивалент) в `pyproject.toml` с `pytest` и `pytest-asyncio`; рантайм-зависимости не меняются.
- **Тесты**: наполняются `tests/unit/` и `tests/integration/` (зеркально `src/dev_helper_bot/`), фикстуры в `tests/conftest.py`.
- **Спеки**: правка `openspec/specs/project-structure/spec.md` (требование о заглушках).
- **Риски**: практически нулевые — удаления касаются только пустых файлов; новая dev-зависимость не попадает в рантайм.
