## REMOVED Requirements

### Requirement: Поддерживающие модули пакета
**Reason**: Требование заставляло хранить пустые файлы-заглушки (`models.py`, `services.py`, `utils.py`) «на будущее» — мёртвый вес без функции; состав модулей должен определяться фактической потребностью, а не заранее заданным списком.
**Migration**: Заглушки удаляются из `src/dev_helper_bot/`; ничего их не импортирует, код не меняется. Новые модули создаются с реальным содержимым по мере появления потребности (см. новое требование «Состав модулей пакета»).

## ADDED Requirements

### Requirement: Состав модулей пакета
Пакет `dev_helper_bot` SHALL содержать только модули с фактической реализацией. Пустые файлы-заглушки без кода MUST NOT храниться в репозитории. Новые модули SHALL создаваться вместе с реальным содержимым, когда возникает потребность.

#### Scenario: Отсутствие пустых заглушек
- **WHEN** проверяется структура `src/dev_helper_bot/`
- **THEN** пустые `models.py`, `services.py`, `utils.py` отсутствуют; остаются только модули с реальной реализацией (`main.py`, `config.py`, подпакет `llm/`)

#### Scenario: Появление новой функциональности
- **WHEN** возникает реальная потребность в новом модуле (модели данных, бизнес-логика, утилиты)
- **THEN** модуль создаётся с фактическим содержимым, а не как пустая заглушка на будущее
