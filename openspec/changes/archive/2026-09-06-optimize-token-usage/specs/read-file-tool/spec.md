# read-file-tool Specification Delta

## Purpose

Инструмент постраничного чтения файлов песочницы с жёсткими лимитами в коде:
дешёвая альтернатива `cat` через `exec`, снижающая объём токенов вывода
инструментов при работе с файлами проекта.

## ADDED Requirements

### Requirement: Постраничное чтение файла
Инструмент read_file SHALL читать файл в песочнице постранично: параметры
path (обязательный), offset и limit (опциональные, в строках). Ответ SHALL
содержать строки с их номерами, чтобы модель могла запрашивать диапазоны.
Длина ответа SHALL ограничиваться жёстким потолком в коде; при обрезке
ответ SHALL сообщать номер строки, с которой можно продолжить чтение.

#### Scenario: Чтение диапазона строк
- **WHEN** модель запрашивает read_file с path, offset и limit
- **THEN** ответ содержит строки файла с номерами в диапазоне от offset,
  не длиннее потолка

#### Scenario: Чтение без offset и limit
- **WHEN** модель запрашивает read_file только с path
- **THEN** ответ содержит первые строки файла с номерами, не длиннее потолка

#### Scenario: Обрыв потолком с подсказкой продолжения
- **WHEN** запрошенный диапазон длиннее потолка ответа
- **THEN** ответ обрезается до потолка и содержит номер строки для
  продолжения чтения следующим вызовом

### Requirement: Ошибки чтения возвращаются модели
Ошибки read_file — отсутствующий файл, каталог вместо файла, ошибки доступа —
SHALL возвращаться модели как текст результата вызова инструмента, а не
исключением; ошибка сама по себе MUST NOT прерывать агентный цикл.

#### Scenario: Файл не найден
- **WHEN** модель запрашивает несуществующий путь
- **THEN** модель получает tool-сообщение с понятной ошибкой, цикл
  продолжается

### Requirement: Чтение из той же песочницы, что и exec
read_file SHALL читать файлы того же изолированного контейнера, в котором
выполняет команды инструмент exec; файлы и результаты команд видны обоим
инструментам согласованно.

#### Scenario: Файл, созданный через exec
- **WHEN** команда exec создала файл, затем модель читает его read_file
- **THEN** содержимое совпадает с тем, что видно через exec
