# token-audit Specification Delta

## ADDED Requirements

### Requirement: Эффективная стоимость с кэш-скидкой
Аудит SHALL рядом с сырой стоимостью (все входные токены по входному прайсу)
отображать эффективную стоимость, в которой кэшированные токены
(cached_tokens) учитываются по отдельному конфигурируемому прайсу со
значением ниже входного по умолчанию. При отсутствии данных о кэше
эффективная стоимость SHALL приравниваться к сырой с явной пометкой, а не
маскироваться. Сравнение «до/после» по целевому снижению стоимости SHALL
вестись по сырым входным токенам; кэш-скидка приводится справочно.

#### Scenario: Есть данные о кэше
- **WHEN** LLM-вызовы в отфильтрованных прогонах содержат cached_tokens
- **THEN** вывод показывает сырую и эффективную стоимость с указанием
  доли кэшированных токенов

#### Scenario: Данных о кэше нет
- **WHEN** отфильтрованные LLM-вызовы не содержат cached_tokens
- **THEN** эффективная стоимость равна сырой, вывод содержит пометку об
  отсутствии кэш-данных
