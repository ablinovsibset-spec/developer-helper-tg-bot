# exec-tool Specification

## Purpose

Универсальный инструмент exec: позволяет модели выполнять произвольные консольные команды в системе и получать их вывод, ограниченный по времени и объёму, с возвратом ошибок самой модели для самокоррекции.

## ADDED Requirements

### Requirement: Выполнение консольной команды
Система SHALL предоставлять модели инструмент exec с единственным обязательным строковым параметром command, выполнять команду в shell системы и возвращать модели результат: стандартный вывод, вывод ошибок и код выхода.

#### Scenario: Успешная команда
- **WHEN** модель вызывает exec с командой, выводящей текст в stdout и завершающейся с кодом 0
- **THEN** модель получает результат, содержащий stdout команды и код выхода 0

#### Scenario: Команда с ненулевым кодом выхода
- **WHEN** модель вызывает exec с командой, завершающейся с ненулевым кодом (например, несуществующая утилита)
- **THEN** модель получает результат, содержащий stderr и фактический код выхода

### Requirement: Таймаут выполнения
Выполнение команды SHALL прерываться по таймауту 30 секунд: процесс завершается принудительно, а модель получает результат с явным признаком таймаута вместо вечного ожидания.

#### Scenario: Долгая команда
- **WHEN** модель запускает команду, выполняющуюся дольше 30 секунд (например, sleep 60)
- **THEN** процесс принудительно завершается и модель получает tool-сообщение о таймауте выполнения

### Requirement: Обрезка длинного вывода
Суммарный вывод команды (stdout и stderr), превышающий ~3000 символов, SHALL обрезаться с сохранением начала и конца вывода и маркера о вырезанной середине, чтобы результат оставался информативным, не разбухал контекст чата и не упирался в лимиты Telegram.

#### Scenario: Команда с длинным выводом
- **WHEN** модель выполняет команду, выводящую 10000 символов
- **THEN** модель получает первые ~1500 и последние ~1500 символов вывода с маркером о количестве вырезанных символов между ними
