# get-skill-tool Specification

## Purpose

Даёт модели инструмент `get_skill`: по имени из каталога в системном
промпте загрузить полное markdown-тело скилла и следовать ему, не держа
все тела в каждом LLM-вызове.

## Requirements

### Requirement: Загрузка тела скилла по имени
Инструмент `get_skill` SHALL принимать обязательный параметр `name`
(строка — идентификатор скилла из каталога) и возвращать полное тело
соответствующего загруженного скилла (markdown без frontmatter). Успешный
ответ MUST NOT включать YAML frontmatter — только тело инструкции.

#### Scenario: Успешная загрузка
- **WHEN** модель вызывает `get_skill` с `name` существующего загруженного
  скилла
- **THEN** результат инструмента — полное тело этого скилла без
  frontmatter

#### Scenario: Имя из каталога промпта
- **WHEN** в системном промпте в каталоге указан скилл `morning`
- **THEN** вызов `get_skill` с `name` равным `morning` возвращает тело
  того же скилла, что был загружен при старте

### Requirement: Ошибки get_skill возвращаются модели
Отсутствие скилла с данным `name`, пустое или отсутствующее имя SHALL
возвращаться модели как текст результата вызова инструмента, а не
исключением; ошибка сама по себе MUST NOT прерывать агентный цикл.

#### Scenario: Неизвестное имя
- **WHEN** модель вызывает `get_skill` с именем, которого нет среди
  загруженных скиллов
- **THEN** модель получает tool-сообщение с понятной ошибкой (имя не
  найдено), цикл продолжается

#### Scenario: Пустое имя
- **WHEN** модель вызывает `get_skill` без имени или с пустой строкой
- **THEN** модель получает tool-сообщение с понятной ошибкой валидации,
  цикл продолжается

### Requirement: get_skill читает in-memory каталог, не песочницу
`get_skill` SHALL возвращать тело из набора скиллов, загруженного при
старте бота из каталога `skills/` хоста (того же, что питает catalog в
системном промпте). Инструмент MUST NOT читать файлы через Docker-песочницу
и MUST NOT подменять `read_file`/`exec` для этой задачи.

#### Scenario: Тело согласовано с загрузкой при старте
- **WHEN** скилл загружен при старте и затем запрошен через `get_skill`
- **THEN** возвращённое тело совпадает с телом, разобранным из файла при
  старте (без повторного чтения с диска в рамках требования согласованности
  с catalog)
