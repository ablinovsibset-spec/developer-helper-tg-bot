# agent-loop Specification

## Purpose

Оркеструет многошаговый агентный цикл: вызывает LLM с контекстом чата и набором инструментов, выполняет запрошенные вызовы, возвращает результаты в контекст и повторяет до финального ответа, защищая от зацикливания пределом шагов.

## Requirements

### Requirement: Агентный цикл до финального ответа
Система SHALL циклически вызывать LLM с текущим контекстом чата и описаниями инструментов: если ход модели содержит вызовы инструментов, система SHALL выполнить их, добавить результаты в контекст как сообщения роли tool и повторить вызов; если ход содержит финальный текст без вызовов инструментов, система SHALL завершить цикл и вернуть финальный текст как ответ пользователю.

#### Scenario: Вызов инструмента и финал
- **WHEN** модель сначала возвращает ход с вызовом инструмента, а после получения результата — финальный текст
- **THEN** система выполняет ровно один вызов инструмента, добавляет его результат в контекст и возвращает финальный текст пользователю

#### Scenario: Финал без инструментов
- **WHEN** модель сразу возвращает финальный текст без вызовов инструментов
- **THEN** цикл завершается без выполнения каких-либо инструментов

#### Scenario: Результат инструмента попадает в контекст
- **WHEN** инструмент выполнен и цикл продолжается
- **THEN** следующий вызов LLM содержит предшествующее assistant-сообщение с вызовами инструментов и tool-сообщение с результатом; reasoning-поле модели в контекст не попадает

### Requirement: Защита от зацикливания
Агентный цикл SHALL выполнять не более 8 вызовов LLM на одно сообщение пользователя. При исчерпании лимита система SHALL прекратить цикл и отправить пользователю сообщение о том, что ответ не был получен за отведённое число шагов, вместо бесконечного повторения или молчания.

#### Scenario: Исчерпание лимита шагов
- **WHEN** модель возвращает вызовы инструментов 8 раз подряд без финального ответа
- **THEN** цикл прекращается после 8-го вызова и пользователь получает сообщение об остановке по лимиту шагов

#### Scenario: Досрочное завершение
- **WHEN** финальный ответ получен на третьем шаге цикла
- **THEN** дальнейшие вызовы LLM и инструментов не выполняются

### Requirement: Ошибки инструментов возвращаются модели
При ошибке использования инструмента — некорректные аргументы вызова, ненулевой код выхода команды, таймаут выполнения — система SHALL возвращать описание ошибки модели как результат вызова инструмента, чтобы модель могла исправить команду или изменить план. Ошибка инструмента сама по себе MUST NOT прерывать агентный цикл.

#### Scenario: Некорректные аргументы вызова
- **WHEN** модель возвращает вызов инструмента, чьи аргументы не являются корректным JSON-объектом с обязательным параметром command
- **THEN** модель получает tool-сообщение с текстом ошибки разбора аргументов, цикл продолжается

#### Scenario: Команда завершилась с ошибкой
- **WHEN** выполненная команда завершается с ненулевым кодом выхода и выводом в stderr
- **THEN** модель получает tool-сообщение с кодом выхода и stderr, цикл продолжается
